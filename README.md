# DOUBLE DOWN

Proyecto Unity 6.3.26f1. Estado: **Fase 2 implementada: mesa jugable de blackjack y sandbox de game feel**.

## Abrir

1. En Unity Hub, añade esta carpeta como proyecto y ábrela con Unity 6.3.26f1.
2. Deja que Package Manager importe URP (que incluye Pixel Perfect Camera), Input System y uGUI.
3. Abre `Assets/_Game/Scenes/BlackjackTable.unity` y pulsa Play. `FeelSandbox.unity` conserva las pruebas de interacción de cartas; `Bootstrap.unity` sigue siendo una escena técnica.
