# DOUBLE DOWN

Proyecto Unity 6.3.26f1. Estado: **Fase 1 terminada; sandbox interactivo de game feel, sin blackjack todavía**.

## Abrir

1. En Unity Hub, añade esta carpeta como proyecto y ábrela con Unity 6.3.26f1.
2. Deja que Package Manager importe URP (que incluye Pixel Perfect Camera), Input System y uGUI.
3. Abre `Assets/_Game/Scenes/FeelSandbox.unity` y pulsa Play. La escena `Bootstrap.unity` sigue siendo una escena técnica vacía.
