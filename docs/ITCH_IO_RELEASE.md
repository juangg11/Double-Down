# DOUBLE DOWN — itch.io

- Proyecto descargable para Windows. Título: **DOUBLE DOWN**. Estado: **In development**.
- Portada: `itch/DoubleDown_Capsule_630x500.png` (630×500, relación 315:250).
- Fondo de página: `itch/DoubleDown_PageBackground_1920x1080.png`.
- Descripción: pegar `itch/DESCRIPTION_ITCH.html` en el modo HTML (`<>`) del editor de itch.io.
- Subir `Builds/DoubleDown-0.1.1-Windows-x64.zip` como descarga de Windows. El usuario publicará la página.
- Capturas reales: `PortfolioMenu.png`, `Phase6Deck.png`, `Phase6Shop.png` y `itch/StarterChoice.png`.

El juego usa ratón y teclado. La versión 0.1.1 incorpora selección de reliquia inicial e interfaz en español e inglés. Los nombres propios de objetos permanecen en español. Las runs no se guardan al salir.

La portada y el fondo son fotogramas estáticos generados con las mismas ecuaciones y paleta del shader `CasinoVortex.shader`. El script `tools/generate_itch_art.py` permite regenerarlos.
