DOUBLE DOWN 0.1.1

Español: Extrae todo el ZIP en una carpeta y abre DoubleDown.exe. Mantén DoubleDown_Data junto al ejecutable. Windows x64. Las partidas no se guardan al salir; los ajustes y controles sí.

English: Extract the complete ZIP to a folder and launch DoubleDown.exe. Keep DoubleDown_Data beside the executable. Windows x64. Runs are not saved on exit; settings and controls are. Item names remain in Spanish.
